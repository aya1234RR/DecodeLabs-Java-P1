# DecodeLabs Java Project 1 - Number Guessing Game

This is my first Java project for my internship at DecodeLabs.

## What it does
The program picks a random number between 1 and 100.
The player has to guess it in 7 tries or less.
After every guess it tells you if you went too high or too low.

## What I learned
- How to use the Random class to generate numbers
- How to take user input with Scanner
- How to use while loops to keep the game running
- How to handle wrong inputs so the program doesn't crash

## How to run it
javac DecodeLabs_Java_P1.java
java DecodeLabs_Java_P1
